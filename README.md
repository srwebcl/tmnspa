# TMN SpA - Plataforma Web Corporativa

Plataforma corporativa y comercial de **TMN SpA** (Transportes Mineros del Norte), especializada en el transporte de carga y logística industrial de punto a punto en el Norte de Chile. 

Desarrollado y optimizado por **SRweb**.

## Tecnologías Utilizadas

- **Framework:** [Next.js 14](https://nextjs.org/) (App Router)
- **Lenguaje:** [TypeScript](https://www.typescriptlang.org/)
- **Estilos:** [Tailwind CSS](https://tailwindcss.com/)
- **Animaciones:** [Framer Motion](https://www.framer.com/motion/)
- **Iconografía:** [Lucide React](https://lucide.dev/)

## Arquitectura y SEO

El proyecto está diseñado para cumplir con los más altos estándares de rendimiento y posicionamiento:
- Arquitectura SEO técnica implementada (Metadata, OpenGraph, robots.txt).
- Optimización de carga de fuentes y assets visuales.
- UI/UX Premium (Diseño corporativo industrial).

## Desarrollo Local

Para ejecutar el servidor de desarrollo en tu máquina local:

```bash
npm install
# Luego
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador para ver el resultado.

## Despliegue en Vercel

Este repositorio está configurado para despliegue continuo a través de **Vercel**. Cualquier push a la rama `main` disparará automáticamente un nuevo build de producción.
